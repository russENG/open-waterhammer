## 0. 事前準備（発表前日〜直前）

| # | 準備 | 理由 |
|---|---|---|
| 0-1 | 会場ネットワークで一度アプリを開き、**計算を1回実行しておく** | Pyodide本体のダウンロードとIndexedDB初期化を済ませる。壇上での初回実行が長時間待ちになるのを防ぐ |
| 0-2 | 直前に **IndexedDBを消す**（ブラウザの「サイトデータを削除」）| 開始画面は常に出るが、前回のプロジェクトが残っていると先頭に「このブラウザーの続きから再開」が並び、Excel導線が2番目に下がる。消しておけばExcelから始まる画面になる |
| 0-3 | **案件名を記入済みのExcel** を1つデスクトップに置く | 後述の[既知の落とし穴 A](#既知の落とし穴)。テンプレートをそのまま上げると必ずエラーになる |
| 0-4 | Excel（またはLibreOffice）が開けることを確認 | 手順2でシートを見せる場合のみ |
| 0-5 | ブラウザの倍率を **125〜150%** に | 入力フォームの文字が小さい |

## 1. 導入（30秒）— 「どこで動いているか」

開始画面（`作業を始める`）を見せながら：

- ブラウザ内だけで完結すること。画面下の **「データの保存場所」** の注意書きを指す。
- 「サーバーに送信されない」「IndexedDBに保存される」「共有は `.owhproj`」の3点だけ言う。

> 話す一言：「計算はすべて手元のブラウザの中です。施設情報がサーバーに出ません」

---

## 2. Excelテンプレートの取得（1分）

1. **01 Excelから開始** の **「入力テンプレートをダウンロード」** をクリック。
   - `waterhammer-template.xlsx`（約23KB）が落ちる。
2. Excelで開いて、シート構成を素早く見せる。

| シート | 見せどころ |
|---|---|
| 使い方 | 「このExcelは初期一括入力。読込後はWeb画面が正本」 |
| 案件情報 | `project_name` が **◎必須**。ここに案件名を入れる |
| 管路・節点 | 列見出しが `記号（説明）＋必須/任意` の3段になっている |
| シナリオ設定 | `case-01 バルブ急閉そく (tv=0.5s)` と `case-02 バルブ緩閉そく (tv=10s)` の2ケース |
| 測点データ | 31測点の縦断データ |

3. **`案件情報` の `project_name` に案件名を入力して保存**。
   例：`デモ：東部幹線水路 水撃圧検討`

> ⚠️ ここを飛ばすと手順3で必ず失敗する（[落とし穴 A](#既知の落とし穴)）。
> 壇上でExcelを触りたくない場合は、**手順0-3で用意した記入済みファイルを使い、テンプレートDLは「こういうものが落ちてきます」と見せるだけ**にする。

---

## 3. 取込（1分）

1. 「入力済みExcelを選択」からファイルを選ぶ。
2. 一瞬で作業画面に切り替わる。左ツリーに案件名、上部に **01〜07のタブ**。

> 話す一言：「Excelの検証に通った場合だけプロジェクトを作ります。エラーなら空のプロジェクトは残しません」

3. **02 モデル＋GIS** を開き、**Excel入出力** カードを指す。
   - 「Excelは初期一括入力、以降はWeb画面が正本」という設計方針をここで説明する。

> ⚠️ 同じ画面の「要素 0」は、**GIS図形が0件**という意味であって管路が取り込めていないわけではない。
> 聞かれる前に「座標を持つ図形はまだ0件です。Excelには座標がないので」と先に言う。

---

## 4. シナリオの確認（1分）

**03 シナリオ** タブ。

- 「編集中のシナリオ」に **バルブ急閉そく / バルブ緩閉そく** の2件がExcelから入っていることを見せる。
- 「比較案＝設備諸元・管路網の違い、シナリオ＝境界条件・操作の違い」という切り分けを説明する。

> ⚠️ 下段の「境界条件 / 操作イベント / 防護工条件」は生のJSONが出る。
> **拡大せず、スクロールで素通りする**。触れる場合は「内部表現をそのまま出しているところで、UI化は今後の課題です」と一言添える。

---

## 5. 解析：A02 Joukowsky / Allievi（2分）— ここが本題

**04 解析** タブ。

1. 「計算方法の選び方（§8.3.2 参照）」の図を開いて閉じる（設計基準の図をそのまま参照していることを見せる）。
2. **A02 Joukowsky / Allievi** を選ぶ。
3. フォームにExcelの値（`pipe-01 / 幹線管路 / D=0.300 / t=0.007 / L=500 / C=130 / V₀=1.0 / H₀=30 / tv=0.5`）が入っていることを指す。
4. **「入力条件を保存」→「▶計算を実行」**。

期待される結果（テンプレート同梱値の場合）：

| 項目 | 値 |
|---|---|
| 波速 a | 1146.7 m/s |
| 4L/a | 1.744 s |
| ΔH（Joukowsky） | **117.0 m** |
| 閉そく区分 | rapid（急閉） |

> 話す一言：「tv=0.5s は 2L/a=0.87s より短いので急閉、Joukowsky式が適用されます。ΔH = aV₀/g = 1146.7×1.0/9.81 ≒ 117 m」

5. 右側の **証跡（計算記録の詳細）** を開き、
   `エンジン: open-waterhammer-core-py` / `実行環境: pyodide-3.13.2` / `由来情報（ハッシュ）` を指す。

> 話す一言：「同じ入力なら同じハッシュになります。再現性の担保はここです」

> ⚠️ 「結果項目」は生キーの羅列（`DELTAHJOUKOWSKY 117.01282324016685`、`K1 null` など）。
> **ハッシュだけ指して素早く閉じる**。

## 6. 手法を変えて再計算：T01 特性曲線法（2分）— 絵が出る山場

計算が終わると比較案は **「計算済み・固定」** になり、解析タブの入力欄と実行ボタンが**すべて無効**になる。

1. **左ツリーの「複製して編集」** を押す（※解析タブ側には出ない。[落とし穴 D](#既知の落とし穴)）。
2. 変更理由を入力：`T01 単一管路の過渡解析（特性曲線法）で再計算`
3. 新しい比較案（編集中）が作られるので、**04 解析** で **T01 単一管路の過渡解析** を選ぶ。

> ⚠️ ここで管路欄が `P-01 / 第1号幹線 / R-01 / J-01`、波速 `1100 m/s` に**入れ替わる**。
> これはExcel由来ではなく組み込み既定値（[落とし穴 E](#既知の落とし穴)）。
> **必ず言及する**：「T01の入力はExcelから作られないので、既定値が入っています。ここでD・t・Lを入力し直します」
> 見せ方を単純化したい場合は既定値のまま回してよいが、その場合は「別条件です」と明言する。

4. 「入力条件を保存」→「▶計算を実行」（10秒程度）。
5. **05 結果** タブへ。

ここで3つの図が出る：

| 図 | 読み取れる値（既定値のまま実行した場合） |
|---|---|
| 時系列 | 弁直上流の水頭変動（0〜8 s） |
| 圧力包絡 | **Hmax 143.4 m / Hmin −39.3 m**（0〜500 m） |
| 縦断 | 定常水頭 |

6. どれか1つの **CSV / SVG / PNG** ボタンを押して、図がそのまま持ち出せることを見せる。

> 話す一言：「最小水頭が負圧域に入っています。水柱分離の検討が要るケースだと分かる」
> ⚠️ ただし **「評価：要確認 / 指摘事項はありません」** と出る。自動判定はまだ入っていないので、
> 聞かれる前に「負圧の自動判定は未実装で、現状は設計者が図から判断する前提です」と言い切る。

## 7. 比較と帳票（1分半）

1. 左ツリーで比較案のチェックを2〜3件入れ、**06 比較** タブ。
   - 「変更理由 / 系譜 / 最新の計算結果」の上3行だけ見せる。
   > ⚠️ その下は生のJSONパス差分（`summary.pipes.P-01.Hmax[10]` など）が延々続く。**スクロールしない**。
2. **07 帳票** タブ。
   - 「保存済みの計算結果」から対象を選び、3つの書き出しを見せる：
     - `Excel帳票`（.xlsx / 約10KB）
     - `計算記録JSON`（.json / 約4KB）
     - `水理計算書・検討書`（.xlsx / 成果品様式）
   - 実際に1つ落として開く。
3. 自動評価の近くにある短い確認事項を示し、詳細な無保証・責任制限は
   **このサイトについて → ライセンス・無保証** に分けていることを説明する。

> 締めの一言：「入力はExcel、計算はブラウザ内、成果はxlsxとJSON。証跡ハッシュ付きで、AGPLで公開しています」

| **G** | T02 管路網の過渡解析 / T04 水撃圧対策設備 は「GIS / 管路網データが必要」で実行できない | この2つは選ばない | — |
