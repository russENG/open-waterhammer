## 1. このデモで見せる範囲

**方針: 農水の成果品様式（水理計算書・水撃圧検討書）に載る項目を最低限すべて通す。**

成果品様式は `packages/excel-io/src/report.ts` の `generateReport()` が出力する4シート。
**07 帳票 → 「水理計算書・検討書」** で、**1ファイル**にまとめて書き出される。

| シート | 内容 | 見せる手順 |
|---|---|---|
| ① 計算結果（21列） | ケース諸元・波速・T₀・α・閉そく区分・ΔH・水撃圧・**設計水圧・許容圧力・余裕度・判定** | S4 → S5 |
| ② 管路データ（9列） | 管路ID・管種・D・t・L・粗度係数・始終点節点 | S3 |
| ③ 案件情報（8行） | 案件名・設計者・作成日付・適用基準・バージョン・計算方法 | S2 |
| ④ 水理計算書（26列） | 測点ごとの Lh/GL/FH/SL/Q/D/CI・動水勾配・V/hv/hf・fb/fv/fβ/Σf/Σhc・h/EL/WLm/hm・Ps/Pi/Pp・**許容圧力・判定** | S6 → S7 |

この4シートを **入力（Excel）→ 画面 → 出力（xlsx）** の3か所で突き合わせるのが、このデモの骨格。

```
入力Excel 5シート          Web画面 7タブ                成果品様式 4シート
─────────────────          ─────────────                ─────────────────
案件情報          ──────▶  01 概要              ──────▶  ③ 案件情報
管路・節点        ──────▶  02 モデル＋GIS       ──────▶  ② 管路データ
シナリオ設定      ──────▶  03 シナリオ          ─┐
                           04 解析 (A02)        ─┴────▶  ① 計算結果
測点データ        ──────▶  04 解析 (L01)        ──────▶  ④ 水理計算書
                           05 結果 / 06 比較
                           07 帳票              ──────▶  1ファイルで書き出し
```

### 使うデータ

入力テンプレートの同梱値は、**農水省 成果品様式の記載例（Ⅱ-170〜171）そのもの**を1本の管路として揃えてある。

| 項目 | 値 |
|---|---|
| 管路 | φ600 ダクタイル鋳鉄管、t = 11 mm、L = 463.224 m（測点の管長 SL の総和）、C = 130 |
| 測点 | 31点（IP.161〜IP.189 ほか）、Q = 0.4515 m³/s |
| 静水位 | 580.600 m（吐水槽 HWL） |
| 末端バルブ | 管中心高 501.030 m → H₀ = 79.570 m、V₀ = Q/A = 1.597 m/s |
| 許容圧力 | 1.6 MPa（呼び圧力） |
| ケース | 急閉そく tν = 0.5 s / 緩閉そく tν = 10 s |

**検算のしどころ**: 記載例の IP.161 は `Ps = 1.03 / Pi = 0.41 / Pp = 1.44 MPa`。
本ツールの計算は `Ps = 1.027 / Pi = 0.411 / Pp = 1.438 MPa` で一致する。

**話す**: 「計算はすべて手元のブラウザの中で走ります。施設情報がサーバーに出ません。保存はIndexedDB、共有は `.owhproj` です」

### S1 — 入力テンプレートの取得（1:30）

**操作**: 01 Excelから開始 →「入力テンプレートをダウンロード」→ Excelで開く

**見せる**: 5シートを順に

| シート | 話すこと |
|---|---|
| 使い方 | 「Excelは**初期一括入力**。読み込んだ後はWeb画面が正本になります」 |
| 案件情報 | 「成果品の表紙にあたる部分。案件名・設計者・適用基準・**静水位**」→ **③に対応** |
| 管路・節点 | 「管種・内径・管厚・延長・粗度係数・**許容圧力（呼び圧力）**」→ **②に対応** |
| シナリオ設定 | 「急閉そく tν=0.5s と緩閉そく tν=10s の2ケース」→ **①に対応** |
| 測点データ | 「31測点。単距離・地盤高・管中心高・管長・流量・管径・流速係数・各損失係数」→ **④の入力列そのもの** |

**話す（要点）**: 「④の水理計算書は24列ありますが、左半分の入力側はこの `測点データ` シートと1対1です。右半分の動水勾配から設計内圧までを、ツールが計算します」

**話す（出典）**: 「同梱の測点データは、農水省の成果品様式の記載例をそのまま収録しています。後で計算結果と記載例を突き合わせられます」

> 落としたファイルは**そのまま次の手順で読み込める**。案件名の書き換えは実案件でのみ必要で、書き換え忘れは取込時に警告が出る。

### S5 — A02 実行と耐圧判定（2:30）→ 成果品様式 ① 右半分

**操作**: 「入力条件を保存」→「▶計算を実行」

**見せる**（結果タブ上部）:

| 成果品様式 ①の列 | 値 |
|---|---|
| 波速 a | **1095.3 m/s** |
| 振動周期 T₀（= 4L/a） | 1.692 s |
| α = tν/T₀ | 0.296 |
| 閉そく区分 | **急閉そく** |
| 水撃圧水頭 ΔH | **178.49 m** |
| 設計水圧 | **2.529 MPa** |
| 自動評価 | **不適合** |

**話す**: 「tν=0.5s は 2L/a=0.85s より短いので急閉そく。ΔH = a·V₀/g = 1095.3 × 1.597 / 9.81 ≒ 178 m。
初期水頭 79.6 m を足して設計水圧 2.53 MPa。呼び圧力 1.6 MPa を超えるので**不適合**です」

**話す（設計の流れ）**: 「つまりこの路線は急閉そくを許容できない。緩閉そくにするか、防護工を入れるかの検討に進む、という判断がここで出ます」

**見せる**: 指摘事項カード（`設計水圧の判定（技術書 §8.3.2）：2.529 / 許容 1.600 MPa`）

**見せる**: 右の「計算記録の詳細」→ `エンジン: open-waterhammer-core-py` / `実行環境: pyodide-3.13.2` / `由来情報`（SHA-256）

**話す**: 「同じ入力なら同じハッシュになります。再現性の担保はここです」

**見せる**（結果タブ上部）:

| 成果品様式 ④の列 | 記号 | 値 |

| 速度水頭 | hv | 0.130 m |
| 摩擦損失水頭 | hf | 0.093 m |
| 損失係数計 | Σf | 0.022 |
| その他損失水頭計 | Σhc | 0.003 m |
| 全損失水頭 | h | 0.096 m |
| ｴﾈﾙｷﾞｰ標高 | EL | 580.504 m |

## 6. デモに使う計算方法

| | 方法 | 採否 | 理由 |
|---|---|---|---|
| A01 | 波速 | △ | 波速・T₀・α は A02 のサマリーにも出るので、単独では使わない |
| **A02** | **Joukowsky / Allievi** | **◎ S5** | 成果品様式①の中核。Excel値がそのまま入り、耐圧判定も走る |
| A03 | 経験式による水撃圧 | △ | 時間があれば |
| S01 | 単一管路の定常解析 | △ | 今回は使わない |
| S02 / S03 | 管路網の定常解析 | △ | Excel由来の値は入らない（案内が出る） |
| **L01** | **縦断水理計算** | **◎ S6** | 成果品様式④そのもの |
| **T01** | **単一管路の過渡解析** | **○ S8** | 図が3枚。既定値に入れ替わる点に注意 |
| T02 / T04 | 管路網の過渡解析・対策設備 | ✕ | 「GIS / 管路網データが必要」で実行不可 |
| T03 | ポンプ過渡解析 | △ | 今回は使わない |

## 7. 画面写真つき静的版

`apps/web-free/public/demo/` に、実機を操作して撮った画面写真つきの手順ページがある。
サイト上部メニューの **「デモ手順」** から開ける。

- 画面写真は Playwright の `apps/web-free/e2e/demo-capture.spec.ts` が撮る
  （`OWH_CAPTURE_DEMO=1 npx playwright test demo-capture --workers=1`）
- ページ本体は `scripts/build-demo-pages.mjs` が `measured.json` を読んで生成する
- 実装を変えたら、この2つを順に流し直せば手順書と画面写真がずれない
