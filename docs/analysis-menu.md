# 数値解析中心の解析メニュー

## 製品方針

実案件の水撃圧検討では、特性曲線法（MOC）による数値解析を主要解析とする。定常解析と波速計算はその準備、Joukowsky・Allievi式と経験式は概算・検算・教育・数値解析との比較に使う簡易確認として位置付ける。

既存の11計算方式、`RunKind`、保存済み計算記録、`.owhproj`、帳票の形式は変更しない。変更するのは画面上の順序、分類、説明、初期選択、入力欄の段階表示だけである。

## 推奨手順

1. 管路・節点・測点とシナリオを確認する。
2. 波速、定常状態、縦断条件を準備計算で確認する。
3. MOCで上昇圧・下降圧、ポンプイベント、防護工の効果を評価する。
4. 簡易式の概算値と比較し、適用基準と不確定要素を踏まえて採用値を検討する。

画面ではこの4段階を常時表示し、主要解析を方式一覧の先頭に表示する。初期選択は、管路諸元の妥当性を最初に確認できる「波速」とする。

## 11方式の分類

| 分類 | 計算方式 | 役割 |
|---|---|---|
| 主要解析 | 管路網の過渡解析、ポンプ過渡解析、水撃圧対策設備、単一管路の過渡解析 | MOCによる時系列の上昇圧・下降圧評価と設計比較 |
| 準備計算 | 波速、管路網の定常解析（Python / EPANET）、単一管路の定常解析、縦断水理計算 | 初期条件、流況、縦断、設計内圧の確認 |
| 簡易確認 | Joukowsky / Allievi、経験式による水撃圧 | 概算、検算、教育、数値解析との比較 |

Joukowsky・Allievi式は急閉・緩閉の理論的な確認に残す。経験式は技術書の適用条件を満たす場合の補助計算とし、負圧を検討する場合や複雑な管路網の数値解析を置き換えない。

## 入力欄の段階表示

通常の確認・変更に使う主要値は最初から表示する。式固有の補足値、任意の許容値、通常は初期値を使う項目は「詳細な計算条件」にまとめ、利用者が開いたときだけ表示する。正準JSONは従来どおり、さらに下位の技術者向け詳細設定として残す。

段階表示は保存データを減らす処理ではない。閉じた入力も従来どおり状態に保持され、保存・計算・帳票に使用される。

## 適用範囲と互換性

- 手法選定ガイドの技術書 §8.3.2 に基づく質問と推奨方式は維持する。
- 既存の計算実行、入力検証、自動評価、保存、帳票、比較機能は同じ`RunKind`を使う。
- 過去の`.owhproj`を開いた場合も、保存済み方式を新しい分類内で選択・表示できる。
- 簡易確認の結果は補助情報であり、主要解析の妥当性、境界条件、数値格子、適用限界を別途確認する。

## テスト

- 11方式が重複・欠落なく3分類に含まれること。
- 「主要解析・準備計算・簡易確認」の順序と、波速から主要解析へ進む導線を確認すること。
- 手法選定ガイドから従来の`RunKind`へ切り替えられること。
- 詳細入力を開閉しても値が維持され、従来の保存・実行経路を使うこと。
