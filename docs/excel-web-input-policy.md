# Excel入力とWeb入力の責任分界

## 結論

Excelは実案件の**初期一括入力**に使用する。読込に成功した後は、ブラウザ内のプロジェクトデータを**正本**とし、確認・修正・計算をWeb画面で続ける。ExcelファイルをWeb画面と並行して更新する運用は想定しない。

作業の保存、共有、別の端末での再開には `.owhproj` を使用する。`.owhproj` は入力、比較案、シナリオ、計算記録を含むプロジェクト全体の交換形式であり、Excelはその代わりにはならない。

## 推奨作業手順

初回画面では「Excelから開始」を実案件の主操作とする。Excelの検証が完了してから、案件情報のプロジェクト名、最初の編集可能な比較案、シナリオ、対応する計算入力を一括作成する。検証に失敗した場合はプロジェクトを作成しない。「空から始める」「サンプルを開く」「`.owhproj`を開く」は補助導線とする。

1. テンプレートに案件情報、管路・節点、測点、初期の操作条件を入力する。
2. 「Excelから開始」または「モデル・GIS」のExcel読込から `.xlsx` を選ぶ。
3. 読込時のエラーと警告を確認する。エラーが1件でもあればプロジェクトデータは更新されない。
4. 読込後はWeb画面で入力を確認し、不足する需要流量、静水位、シナリオなどを補う。
5. 計算を実行し、計算記録と結果を確認する。
6. 節目ごとに `.owhproj` を書き出して保存・共有する。

## Excel項目とWebデータの対応

| Excelシート・項目 | 読込後の保存先 | Webでの用途 | 読込規則・制約 |
|---|---|---|---|
| 案件情報 | `modelSnapshot.excelImport.meta` | 由来情報、帳票 | 現状は既存プロジェクト名を変更しない。「Excelから開始」では案件名を新規プロジェクト名に使う |
| 管路・節点：先頭の管路 | `wave_speed` の計算入力 | 波速計算 | 先頭行だけを使用 |
| 管路・節点：先頭の管路、ケース設定：先頭行 | `joukowsky_allievi` の計算入力 | 簡易水撃圧計算 | それぞれ先頭行だけを使用 |
| 管路・節点：全行 | `steady_network_python`、`steady_network_epanet` の計算入力 | 定常管路網計算 | 管路と節点が両方ある場合に作成。需要流量はExcelに列がないためWebで補う |
| 測点データ：全行 | `longitudinal_hydraulics` の計算入力 | 縦断水理計算 | 静水位は0で初期化するためWebで確認・修正する |
| ケース設定：先頭行の等価閉そく時間 | 現在の比較案に属する先頭シナリオの `eventSettings.closeTime` | 操作イベント | 値がある場合だけ上書きする。他のシナリオ条件は保持する |
| 読み取った全シート | `modelSnapshot.excelImport` | 由来情報、成果品様式の帳票 | 再読込時は全体を置き換える |

ケース設定の複数行とシナリオの関係は [Issue #19](https://github.com/russENG/open-waterhammer/issues/19) で再設計する。それまでは先頭行だけが計算入力と操作イベントに反映される。

## Web画面で入力する項目

Excelにない項目、読込時に既定値となる項目、読込後に変更する項目はWeb画面で入力する。主な対象は次のとおり。

- 需要流量、静水位、許容圧力など、Excelから完全には作れない計算条件
- 境界条件、操作イベント、防護工条件などのシナリオ
- GISの座標系、属性割当、読込後の管路網
- Excelに対応しない数値解析の入力

Webで修正した値をExcelへ自動的に書き戻す機能はない。読込後の正本はWeb画面の値である。

## Excel再読込の上書き規則

再読込は、読込先が「編集中」の比較案である場合に限り、確認画面を経て実行できる。

上書きするもの：

- 新しいExcelから作成できた計算種別の入力
- `modelSnapshot.excelImport` に保存したExcel由来情報の全体
- 新しいExcelに値がある、先頭シナリオの対応する操作イベント項目

保持するもの：

- 新しいExcelから作成されなかった計算種別の既存入力
- シナリオの境界条件、防護工条件、Excelに値がないその他の操作イベント項目
- 比較案のID、名前、状態、派生関係
- 保存済みの計算記録

検証エラーが1件でもある場合、または取り込めるデータがない場合は何も更新しない。再読込前の値を履歴として自動保存しないため、元の状態を残す必要がある場合は再読込前に `.owhproj` を書き出す。計算済み・固定または保管済みの比較案には再読込できない。

## ファイルの位置付け

| 形式 | 役割 | 正本として扱う時点 |
|---|---|---|
| `.xlsx` | 初期一括入力、既存データからの再入力 | 読込前まで |
| ブラウザ内のプロジェクトデータ | 確認、修正、計算を行う作業中データ | Excel読込後 |
| `.owhproj` | プロジェクト全体の保存、共有、作業再開 | 書き出した時点の固定スナップショット |
