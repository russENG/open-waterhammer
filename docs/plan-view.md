# 管路平面図・模式図

## 表示方針

管路・節点を読み込んだ比較案の概要には、正準水理モデルから平面図を自動表示する。入力元ごとの描画処理は持たず、Excel、GeoJSON、Web入力が同じ正準モデルになった場合は同じ図を表示する。

| 条件 | 表示 | 画面での明示 |
|---|---|---|
| 正準モデルの全節点に有限のXY座標がある | 実座標平面図 | 座標系を併記する。管路中心線があれば折れ線を使い、なければ始終点を直線で結ぶ |
| 正準モデルはあるが全節点の座標が揃わない | 模式図 | 「位置・距離は実座標ではありません」と表示する。接続関係から自動配置する |
| 正準モデルに管路・節点がない | 未設定表示 | 管路・節点モデルが未設定であることを表示する |

座標が一部だけある場合に実座標と模式配置を混在させると距離・方位を誤認しやすいため、図全体を模式図に切り替える。

## 入力仕様

alpha版では、Excelの「管路・節点」シートへ座標列を追加しない。Excelは水理諸元の初期一括入力に使い、実座標は次の手順で追加する。

1. Excelを読み込み、管路・節点の正準IDを作成する。
2. 同じ管路ID・節点IDを持つGeoJSONを「モデル＋GIS」で読み込む。
3. GISの節点座標と管路中心線だけを、同一IDの正準要素へ統合する。
4. 一致しないIDと不正要素は編集中GISデータに残し、推測で正準モデルへ追加しない。

Web入力から正準モデルへ保存された節点座標・管路中心線も同じ形式で描画できる。Excelへ座標列を追加する場合は、CRS、XYの単位、管路中心線の表現、再読込時の競合規則を別Issueで定義してから行う。

## 自動配置

- 管路の始終点IDから接続成分を求める。
- 入次数0の節点を左側の起点とし、下流方向を右側へ層状に配置する。
- 同じ深さの分岐節点は上下へ分ける。
- 閉路など起点を決められない成分は、ID順の最初の節点から配置する。
- 主な接続成分以外は上下に分離し、「要確認」として表示する。

模式図の線長・方向・節点間隔は、実延長、方位、縮尺を表さない。

## 識別表示

- 管路: 実線と管路ID
- 貯水池・水槽、接続節点、調整水槽、ポンプ、バルブ: 種別ごとの記号
- 主な管路網から分離した成分: オレンジの破線
- 管路に接続されていない節点: オレンジの記号
- 存在しない節点を参照する管路: 赤の破線と欠損節点記号

接続確認は図とメッセージの両方で示し、色だけに依存しない。
