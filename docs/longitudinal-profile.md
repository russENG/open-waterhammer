# 入力・計算結果の縦断図

## 目的

Excelを読み込んだ直後から、測点の水平距離・地盤高・管中心高を図で確認できるようにする。計算前の入力確認図と、保存済み計算結果を重ねた図は、同じ正準測点を横軸に使いながら明確に区別する。

## 表示区分

| 表示 | 使用データ | 表示場所 |
|---|---|---|
| 入力確認図（計算前） | 正準測点の水平距離、地盤高、管中心高、所属管路、節点参照 | 概要 |
| 計算結果重ね合わせ図 | 入力系列に、保存済み計算結果の動水位、最大・最小水頭、設計内圧換算水頭を追加 | 結果 |
| 入力確認図（計算結果なし） | 正準測点はあるが、対応する保存済み結果系列がない | 結果 |

図の再表示では再計算しない。計算系列は保存済みの`Run.summary`だけから取り出す。

## 横軸と管路区間

- 測点は`sequence`順に並べる。入力順と異なる場合、または順序番号が重複する場合は警告し、該当測点を要確認表示する。
- 横軸は`horizontalDistanceFromPrevious`の累計値とする。
- 同じ管路内では、水平距離と`distanceAlongPipe`の差分を照合する。差が0.5 mまたは1%の大きい方を超えた場合は距離不整合とする。
- `distanceAlongPipe`が負、または管路延長を超える測点は管路範囲外として表示する。
- 所属管路が切り替わる位置に管路IDと管径を表示し、管径変化を識別できるようにする。

## 欠損・不正値

- 地盤高または管中心高が有限の数値でない場合、その系列は該当位置で切断し、値を補間しない。
- 水平距離が負または不正な場合、累計距離を進めず、前の有効位置に要確認記号を置く。その処理をメッセージで明示する。
- 所属管路、参照節点、管路内距離を解決できない場合は要確認記号と理由を表示する。
- 問題のある測点を非表示にせず、利用者が元データへ戻れるようIDを保持する。

## 計算結果の重ね合わせ

### 縦断水理計算

最新または画面で選択した成功済み`longitudinal_hydraulics`の`pointResults`を測点IDで対応付ける。

- `hydraulicGradeLine`: 動水位として表示
- `designPressure`: MPaから水頭へ換算し、管中心高へ加えた「設計内圧換算水頭」として表示

設計内圧は標高ではないため、換算水頭であることを凡例に明記する。

### 過渡解析

成功済み過渡解析の管路別`H_steady`、`Hmax`、`Hmin`を、測点の`distanceAlongPipe / pipe.length`で線形参照する。結果配列がない管路・測点は補間対象にせず、その系列を表示しない。

## 選択連動

測点を選択すると、次の参照を1つの選択状態にまとめる。

- 縦断図: 測点ID
- 平面図・GIS: 一致する節点ID、なければ管路ID
- 圧力包絡: 所属管路ID
- 時系列: 一致する節点ID、なければ所属管路ID

管路区間を選択した場合は、平面図・GIS・圧力包絡・時系列を管路IDで連動する。マウス操作だけでなく、キーボードのEnter・Spaceでも選択できる。
