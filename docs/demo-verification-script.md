# 検証デモ手順書 — 成果品様式カバレッジ版

**版**: v0.2（2026-08-26）／改訂前提
**対象**: `apps/web-free`（Pyodide `pyodide-3.13.2`）
**目的**: 成果品様式（水理計算書・水撃圧検討書）に載る項目を、**画面と書き出しファイルの両方で**
一つずつ確認する。デモの進行は [demo-plan.md](demo-plan.md) を参照。

> **v0.2 での変更**: [#26](https://github.com/russENG/open-waterhammer/issues/26)〜[#40](https://github.com/russENG/open-waterhammer/issues/40) の修正を反映。v0.1 にあった回避策（案件名の手書き換え、
> L01 の JSON 手編集、帳票の2ファイル分割）はすべて不要になり、期待値も入れ替わっている。

| 列 | 記号 | 単位 | 出所 | 現状 |
|---|---|---|---|---|

| 損失係数計 Σf / その他損失水頭計 Σhc / 全損失水頭 h | — | m | L01 | ○ |
| ｴﾈﾙｷﾞｰ標高 EL / 動水位 WLm / 動水頭 hm | — | m | L01 | ○ |

### V5 — A02 実行と耐圧判定 → 成果品様式 ① 右半分

| | |
|---|---|
| **操作** | 「入力条件を保存」→「▶計算を実行」 |

| 項目 | 期待値 | 判定 |
|---|---|---|
| 波速 a | **1095.3 m/s** | □ |
| 振動周期 T₀ | 1.692 s | □ |
| α = tν/T₀ | 0.296 | □ |
| 閉そく区分 | **急閉そく** | □ |
| 水撃圧水頭 ΔH | **178.49 m** | □ |
| 自動評価 | **不適合** | □ |
| 指摘事項 | 1件・`設計水圧の判定（技術書 §8.3.2）：2.529 / 許容 1.600 MPa` | □ |

**検算**: ΔH = a·V₀/g = 1095.3 × 1.597 / 9.81 ≒ 178 m。2L/a = 0.846 s > tν = 0.5 s なので急閉そく。
設計水圧 = (79.570 + 178.49) × 9.8/1000 = 2.529 MPa。

許容圧力を変えたときの期待判定:

| 許容圧力 | 余裕度 | 判定 |

| 3.0 MPa | 15.7% | 適合 |
| 2.7 MPa | 6.3% | 注意 |
| **1.6 MPa** | −58.1% | **不適合** |
