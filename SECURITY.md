# Security Policy

Open Waterhammer is an alpha design-comparison aid. Do not include real project data,
credentials, private infrastructure details, or exploit details in a public issue.

Report a suspected vulnerability with GitHub's private vulnerability reporting feature
from this repository's **Security** tab. If private reporting is unavailable, open a
minimal public issue asking the maintainer for a private contact channel without including
the vulnerability details.

Only the latest tagged release and the current default branch receive security fixes.
The browser application's security and data boundaries are documented in
[`docs/security.md`](./docs/security.md).
